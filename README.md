# Balenciaga Track — Showcase

**[Live demo →](https://tranqww.github.io/balenciaga-track-showcase/)**

An interactive 3D product showcase for the Balenciaga Track sneaker, built with [three.js](https://threejs.org/). A full-bleed WebGL hero renders four real colorways as real GLB models — drag to rotate, scroll to zoom, cycle through Black/Bordeaux, Triple White, White/Orange, and Track 2.0 Black.

This repo holds the built, static output deployed to GitHub Pages. It's a showcase mirror of the source project — no build step lives here.

## Stack

- [three.js](https://threejs.org/) — GLTF loading, PMREM/RoomEnvironment lighting, custom transition animation
- Vite — build tooling (in the source repo)
- Vanilla JS, no framework
